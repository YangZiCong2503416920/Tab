# StartTab · 个人浏览器起始页

个人自定义的浏览器起始页：玻璃拟态界面、书签分组、待办、自定义搜索引擎、小组件、天气、壁纸库。
**技术栈：TypeScript + Vite + 单文件构建**，运行时零依赖，数据全部保存在浏览器 localStorage。

## 怎么使用

### 直接使用（file:// 方式）
1. Clone 本仓库：`git clone https://github.com/YangZiCong2503416920/StartTab.git`
2. 浏览器设置 → 初始页/启动时 → 自定义路径，指向仓库根目录的 `index.html`
   （该文件由构建自动生成、自包含所有代码，无需安装任何依赖即可运行）

### 开发
```bash
npm install        # 安装开发依赖
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 类型检查 + 构建单文件 + 复制到根目录 index.html
npm test           # 单元测试（vitest + jsdom）
npm run preview    # 预览构建产物
```

## 功能特性
- 🔍 **多引擎搜索**：内置 Google/Bing/百度/DuckDuckGo，支持添加常用引擎预设（GitHub/知乎/B站/淘宝等）
- 🌐 **快速翻译**：点翻译按钮，或输入 `译 xxx` / `fy xxx` 直接中英互译
- 🔖 **书签管理**：增删改、拖拽排序、**分组管理**（按场景组织）、自动获取网站图标
- ✅ **待办事项**：优先级、截止日期、逾期提醒、状态过滤、批量清除
- 🧩 **小组件系统**：时钟、日历（标注待办到期日）、天气、倒数日（含摸鱼倒计时）、便签，可开关
- 🖼️ **壁纸库**：渐变预设（离线）/ Bing 每日壁纸 / 随机图片 / 自定义 URL / 本地文件
- 🎨 **深浅主题**：跟随系统 / 深色 / 浅色
- ⌨️ **快捷键**：`/` 搜索 · `t` 待办 · `n` 新建书签 · `?` 帮助 · `Esc` 关闭
- 💾 **数据备份**：导出 JSON / 导入恢复（严格校验）/ 一键重置

## 稳定性设计
- 存储**版本化迁移**（schema v2）与**数据修复**：坏数据自动丢弃/纠正，老版本数据自动升级
- 所有网络请求带**超时与自动重试**（天气/壁纸），失败优雅降级不崩溃
- 全局异常兜底：未捕获错误弹提示，页面保持可用
- 渲染通知**可重入保护**，避免组件重复渲染
- 单元测试（vitest）+ 构建产物集成测试

## 目录结构
```
src/
  core/       存储层（版本化/迁移/修复）、工具、toast
  features/   书签、待办、搜索、天气、壁纸、小组件、设置、数据 IO
  ui/         模态框
  index.html  页面模板（Vite 入口）
tests/        单元测试
scripts/      构建产物复制脚本
```
