# StartTab · 个人浏览器起始页

个人自定义的浏览器起始页，纯原生 HTML/CSS/JS，零依赖、零构建，数据全部保存在浏览器 localStorage 中。

## 怎么使用
* 直接 Clone 使用 https://github.com/YangZiCong2503416920/StartTab.git
* 在浏览器设置 → 初始页/启动时设置 → 自定义路径指定该 index.html

## 功能特性
* 🔍 **多引擎搜索**：内置 Google / Bing / 百度 / DuckDuckGo，支持搜索历史
* ⚙️ **自定义搜索引擎**：设置里可以自由添加、编辑、删除搜索引擎，可设默认
* 🔖 **书签管理**：页面上直接增删改书签，支持拖拽排序、Emoji 图标或自动获取网站图标
* ✅ **待办事项**：支持优先级（高/中/低）、截止日期、逾期提醒、状态过滤、批量清除已完成
* 🎨 **深浅主题**：跟随系统 / 深色 / 浅色，一键切换
* 🖼️ **自定义壁纸**：支持图片 URL 或本地图片文件
* 🌤️ **天气小组件**：基于 Open-Meteo 免费 API（无需密钥），支持中文城市名，可自动定位
* ⌨️ **键盘快捷键**：`/` 搜索 · `t` 待办 · `n` 新建书签 · `?` 帮助 · `Esc` 关闭
* 💾 **数据导入导出**：全部数据可导出 JSON 备份、导入恢复、一键重置

## 数据说明
所有数据存于 localStorage（键前缀 `tab.`），清除浏览器数据前请先导出备份。
